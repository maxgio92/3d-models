# Hario V60 Kettle Thermometer Holder 45x15x3.8

Flat tapered open collar for holding a thermometer on a Hario V60 pour-over
coffee kettle. The side opening lets it push sideways between two columns while
the closed ends help keep the columns captured.

- Overall length: `45 mm`
- Height: `3.8 mm`
- Wide-end outside diameter: `15 mm`
- Narrow-end outside diameter: `7 mm`
- Wall width: `1.5 mm`
- Side opening inset from each end: `8 mm`

Generate the STL:

```sh
openscad \
  -o coffee/hario/hario-v60-kettle-thermometer-holder-45x15x3p8/hario-v60-kettle-thermometer-holder-45x15x3p8.stl \
  coffee/hario/hario-v60-kettle-thermometer-holder-45x15x3p8/hario-v60-kettle-thermometer-holder-45x15x3p8.scad
```
